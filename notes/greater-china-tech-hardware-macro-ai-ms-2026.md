# 大中华区科技硬件：宏观不确定性会压制AI硬件前景吗？

**来源**：Morgan Stanley Asia Pacific，2026-04-16  
**结论**：宏观阴云下，AI 服务器硬件势头不减；消费电子受内存通胀拖累，需谨慎

---

## 机遇领域

### AI GPU/ASIC 服务器/机架设计升级
- Vera Rubin 平台、Kyber 架构、LPX/Vera CPU 机架 → 重大设计升级
- AI ASIC（TPU/Trainium）服务器升级 + 扩量
- GB300 服务器机架交付顺利 + AI ODM 吸引力的风险回报

### 近期股价上行空间
- **AI 服务器电源方案**：800 VDC 直流电（新一代电源架构）
- **PCB/ABF 基板供应紧张**
- **数据网络/互联/CPO 升级**
- **供应链产能扩张浪潮**

## 主要风险
1. **消费电子（手机/PC）**：2H26 受内存通胀影响，需求和利润率承压
2. **原材料涨价**（铜、镍）和供应紧张 → 毛利率逆风
3. **供应短缺**可能延迟出货节奏
4. **地缘政治**风险影响 AI 数据中心基础设施支出

## CPU 拉动供应链量化估算

**每增加 100 万颗服务器 CPU 的影响**：
- Unimicron ABF 基板：营收上行约 0.2%（ABF ASP $12.6/颗）
- Lotes CPU 插槽：营收上行约 0.6%（Socket ASP $21.9/颗）
- FIT（连接器）：相应获益

若 CPU TAM 增长 10-15M 颗：
- Unimicron ABF 营收上行约 2.9%
- Lotes CPU 插槽营收上行约 7.3%
