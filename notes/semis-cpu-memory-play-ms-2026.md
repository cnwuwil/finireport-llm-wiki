# 半导体：微处理器走强，但存储仍是把握趋势的首选

**来源**：Morgan Stanley，2026-04-20  
**核心结论**：Agentic AI 带动服务器 CPU 需求走强，但 INTC/AMD 的投资性价比不如内存股 MU/SNDK

---

## 核心观点

- CPU 正成为 AI 浪潮中更重要的组成部分：AI Agents 大量运行在 CPU 上
- 全球团队预计 CPU 长期增长率 ~30-40%，远高历史水平，但仍低于 GPU 预期
- **评级首选**：MU（5.7x CY26）> SNDK（11.5x CY26）> AMD（EW）> INTC
- 原因：内存股估值更低、多重催化剂、数据中心超大规模云厂商至少到 2027 年供应紧张

---

## Intel（INTC.O）

- PT 从 $41 上调至 $56；EPS 上调 8%（CY26）/ 38%（CY27）；现高出 consensus 约 20%
- **上调逻辑**：服务器 like-for-like 价格上升 + 量增
- **限制因素**：
  - 服务器产品路线图近期仍有挑战（Diamond Rapids 明显弱于 AMD Venice，CEO 本人已承认）
  - 以"有 Fabs"争取市场份额的逻辑不成立（AMD 新品在台积电 N2，不稀缺）
  - 铸造业务（Foundry）仍持怀疑态度，Terafab 合作尚待观察
- DCAI（数据中心/AI）：CY26 预测 +30% Y/Y（服务器单量 +14% + ASP +20%）
- CCG（客户端/PC）：CY26 降 8% Y/Y（内存涨价压制 PC 需求）

---

## AMD（AMD.O）

- 评级：Equal Weight，PT $255（~27x CY27E Non-GAAP EPS $9.46）
- **服务器 CPU**：产品领先优势明显（Venice 大步领先），但估值已反映预期
- **AI GPU**：主论点仍为 MI455；管理层对 1Q 之后毛利率指引偏谨慎
- **挑战**：AMD 会用 CPU 配额撬动 GPU 采用，可能给折扣，压制服务器 CPU 利润率
- 关键观察：MI455 GPU 业绩改善比服务器 CPU 更能驱动股价

| 情景 | 价格 | EPS基础 |
|------|------|---------|
| 牛市 | $450 | ~37x CY25E $10.94 |
| 基准 | $255 | ~27x CY27E $9.46 |
| 熊市 | $140 | ~20x CY27E $7.00 |

---

## 为何优选存储（MU / SNDK）

- 估值：MU 5.7x CY26 / SNDK 11.5x CY26，远低于 CPU 股
- 数据中心超大规模云厂商 2027 年前完全无法通过现货市场满足需求
- 现货价格局部走弱（如零售散装内存）≠ 数据中心供应松动
- 长期协议（LTA）：内存厂商正与客户签署预付款协议（非违约金），比过去更难反悔
- 内存作为"CPU/AI 算力放大器"，是同一趋势的受益者，估值折扣更大
