## 三大核心主题

### 1. DDR4：供紧但动能减速

- DDR4 8Gb 价格预计很快突破 USD 20（4Gb 突破 USD 10）
- 2Q26 涨幅约 +60%，但 2H26 开始减速
- **限制因素**：
  - KV cache 压缩（AI 推理优化减少内存需求）
  - 服务器系统优化
  - LTA（长期协议）谈判影响价格弹性
  - CXMT 开始增加 DDR4 支撑供给
- 因此：DDR4 厂商短期盈利高但股价上行受限

### 2. 旧版闪存（Legacy Flash）：涨价加速

- **MLC NAND**：供应极度紧张，Kioxia 退出、Samsung 退出后，Macronix 主导
  - 2Q26 价格可能上涨高达 100%
  - 2H26 仍维持高位双位数涨幅
- **NOR Flash**：Macronix 将部分产能转向 MLC NAND，NOR 供给减少
  - NOR 价格 2Q26 亦可能涨高达 100%
- **首选**：Macronix（涨价最直接受益，上行空间 109%，下行 -24%，风险/回报 4.5x）

### 3. Intel EMIB-T：AP Memory 的新机遇

- Intel EMIB（嵌入式多芯片互连桥）相较 CoWoS 更模块化、成本更低，但带宽密度不及 CoWoS
- Intel EMIB-T 新架构：垂直铜连接（TSVs）嵌入有机基板，支持 HBM4 高速内存集成
- **AP Memory 是核心受益**：提供嵌入式深沟槽电容（eDTC，即 IPD 产品），用于电源稳定
  - 每芯片内容价值可达约 USD 100（高功耗 ASIC 如 TPU 场景）
  - 增量营收潜力：较 2026E 水平 +50%+
- **客户进展**：Google 和 AWS 已接触 Intel EMIB-T 进行机械测试（MTV）
  - MediaTek 下一代 2nm TPU 可能相关
  - Alchip 下一代 2nm Trainium4（与 Intel 已有 Gaudi 合作经验）
  - 试产预计 2027 年，量产 2028 年
- **不确定性**：Intel EMIB-T 量产良率、TSMC CoWoS/CoPoS 配额分配仍待观察

## PSMC 规格迁移亮点

- PSMC（6770.TW）在 2027 年的规格迁移（Spec Migration）将是主要亮点
- 当前估值：FY26e P/E NM（亏损），FY27e P/E 6.7x；FY26 EPS 低于 consensus 44.9%
