# 2026 存储超级周期：DRAM / NAND / NOR / HBM 全线上行

## Thesis（当前论点）

2026 年存储市场进入以 AI 为驱动、以数据中心客户为锚的价格超级周期。与以往消费电子驱动的存储周期不同，本轮涨价有三个结构性支撑：（1）数据中心/AI 工作负载对 DRAM、NAND、HBM 的增量需求远超历史峰值；（2）供应商审慎扩产，叠加中国厂商质量风险使国产替代难以在短期内冲击价格；（3）长期合同（LTA）锁价，降低了价格快速反转的可能性。

各细分子类中，**旧式闪存（MLC NAND / NOR）涨幅最激进，DDR4 也在上行但后劲有限，HBM 是 AI 加速器市场的不可替代组件**。

## 各细分市场分析

### HBM（高带宽内存）

- AI GPU/ASIC（NVDA Blackwell、AMD MI450、Google TPU）的不可替代组件
- 供应紧张：JPM 预测 HBM 供应将持续紧张至 CY27
- 主要受益：SK Hynix（全球最大 HBM 供应商）、Micron（MU）、Samsung

### DRAM（DDR4/DDR5）

- **短期涨价强劲**：DDR5 现货 +573% YoY，合约价 2Q26E +421% YoY
- **后劲疑问**：
  - KV cache 压缩（AI 推理优化）可能减少推理端 DRAM 需求
  - CXMT 开始增加 DDR4 供给
  - LTA 谈判影响价格弹性
- MS 判断：DDR4 厂商短期盈利高，但股价上行受限；**估值优先选 DRAM（MU）而非 CPU 股**
- MS 评级优先级：MU（5.7x CY26 P/E）> SNDK（11.5x CY26）> AMD > INTC

### NAND（MLC / TLC / eSSD）

- **Sandisk（SNDK）**：BofA 目标价 $1,080（+70%+ 上行空间）
  - F3Q26E ASP +70% QoQ，毛利率从 51% → 78.5%（F4Q28E）
  - 2027E EPS $110.62，2027E 营收 +87% YoY
  - 数据中心客户比例快速提升（1% → 15%），周期性降低
  - LTA 策略锁定收入能见度

### NOR / MLC NAND（旧式闪存）

- **最强涨价周期**：Kioxia / Samsung 退出 MLC NAND，Macronix 主导
- Macronix 将 NOR 产能转向 MLC NAND → NOR 供给减少，两者同步涨价
- MS 风险/回报：Macronix 上行 +109% / 下行 -24% = 4.5x（最优）

## 矛盾 / 待解问题

- **现货 vs 合约价背离**：DRAM 现货 -6.1% MoM 但合约 +61% QoQ（2Q26E）——是库存轮换信号还是需求减弱？JPM 倾向前者，但需跟踪
- **KV cache 压缩的影响程度**：AI 推理效率提升可能部分对冲 Agentic AI 的 DRAM 需求，MS 已提示但未量化
- **CXMT / YMTC 产量爬坡**：若中国产能快速提升，将对 DDR4 / MLC NAND 价格形成压制；目前质量仍是瓶颈
- **LTA 策略的脆弱性**：合同"部分可变"，若数据中心客户 Capex 削减，LTA 锁价能否坚守？
