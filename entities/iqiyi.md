# 爱奇艺 iQIYI Inc. (IQ)

中国最大长视频流媒体平台，以精品自制剧和 IP 生态见长。纳斯达克上市（IQ），正推进港股二次上市。

## 基本面快照（截至 2026-04）

| 项目 | 数值 |
|------|------|
| 市值 | ~$1.4bn |
| 企业价值 | ~$2.4bn |
| 当前股价 | $1.41（2026-04-17） |
| 净债务/EBITDA | 7.7x（2025A），去杠杆中 |
| 主要收入来源 | 会员订阅（为主）+ 广告 |

## 核心竞争力

- **长剧 IP**：精品自制剧是生成可持续 IP 及衍生品的主要载体（与短视频平台的本质差异）
- **AI 制作能力**：Seedance 2.0 + NaDou Pro，目标 2027-2028 大幅降低制作成本（至现有 <20%）
- **版权库**：多年积累的数字资产，支撑 AI 模型训练和角色授权

## 战略方向（2026）

1. AI 原生长剧（Q3 2026 首发）
2. 出海：东南亚年轻女性用户，中国内容超越韩剧
3. 港股二次上市（进行中）
4. 不自研大模型，用开源 + 公有云控成本
