# Jentech Precision Industrial Co. 精成科技 (3653.TW)

全球最大封装级散热组件制造商，专注于高端 AI GPU 热扩散盖（IHS）产品。台湾证交所上市（3653.TW）。

## 核心产品

- **Heat Spreader（IHS）**：stiffener ring + lid 方案，用于 AI GPU（NVIDIA Blackwell/Rubin、AMD MI series）
- **Micro-channel Lid**：高密度散热盖，次世代高端选项
- **Cold Plate**：液冷散热解决方案（新兴）
- **CPU Server Socket**：服务器 CPU 底座（新兴）
- **CPO Switch ASIC 散热**：未来 TAM 扩张方向

## 竞争地位

- **高端服务器芯片散热器唯一供应商**（sole supplier）
- 技术壁垒高：特种金属加工、精密复合材料，进入门槛极高
- 2024-28E EPS CAGR ~60%，受益于每颗 GPU 价值量（content value）持续提升
